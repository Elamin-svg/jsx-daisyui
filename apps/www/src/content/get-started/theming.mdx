# Theming

daisyUI JSX uses daisyUI v5 under the hood. The docs site ships DaisyUI's default `light` and `dark` themes.

---

## Using daisyUI themes

Set the `data-theme` attribute on your root element:

<CodeBlock
  code={`export default function App() {
  return (
    <html data-theme="dark">
      {/* All components will use the dark theme */}
    </html>
  );
}`}
  label="app.tsx"
/>

The docs site uses DaisyUI's default `light` and `dark` themes. When you use the components in your own project, any built-in DaisyUI theme will work fine.

The full list of built-in themes is at [daisyui.com/docs/themes](https://daisyui.com/docs/themes).

---

## Docs site

The docs site previews components in light and dark mode only. The library does not ship custom themes.

---

## Component-level styling

Every component accepts a `className` prop. Pass any Tailwind or daisyUI class directly:

<CodeBlock
  code={`import { Button } from "@/components/ui/button";

export default function App() {
  return (
    <Button className="btn-secondary">
      Styled Button
    </Button>
  );
}`}
  label="app.tsx"
/>
